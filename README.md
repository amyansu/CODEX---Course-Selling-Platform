# 🚀 CODEX — Online Course Selling Platform

A full-stack course-selling platform where students can explore courses, enroll, and access their learning content. Admins can manage courses through a dedicated admin panel.

## ✨ Features

### 👤 Student Features
- **Authentication** – Signup, Login & JWT-based authentication.
- **Role-Based Access** – Separate access for Students and Admins.
- **Home Page** – Explore the platform and discover courses.
- **Browse Courses** – View all available courses.
- **Course Details** – View course information and pricing.
- **Course Enrollment** – Enroll in courses.
- **My Courses** – View all enrolled courses.

### 🛠️ Admin Features
- **Admin Dashboard** – Dedicated admin panel.
- **Manage Courses** – View courses created by the admin.
- **Add Course** – Create new courses.
- **Edit Course** – Update existing course details.
- **Delete Course** – Remove courses.
