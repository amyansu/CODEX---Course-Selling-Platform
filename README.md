# CODEX - Course Selling Platform

## Tech Stack
- React
- Node.js
- Express
- TypeScript
- Drizzle ORM
- Neon PostgreSQL
- JWT Authentication

## Features
- User Signup & Signin
- JWT Authentication
- Admin Authorization
- Course Management
- Course Enrollment
- My Courses
- Admin Dashboard

## Backend Setup
1. Clone repository
2. cd server
3. npm install
4. Configure .env
5. npm run dev

## API Testing
Import postman/CODEX.postman_collection.json
into Postman.
